# 추가 분석 후보

현재 7개 핵심 서비스 다음으로 볼 가치가 큰 후보입니다.

## 우선순위 A

### Cabri Express
- 동적 기하
- 브라우저 기반
- GeoGebra와 다른 작도 UX 비교 가치
- 도형 도구의 '선택 순서'와 객체 제약 분석 필요

### Brainingcamp / Virtual Manipulatives
- 초등 가상 교구
- 수모형을 하나의 작업공간에 모으는 방식
- Polypad·MLC와 비교 가치가 큼

### Didax Virtual Manipulatives 계열
- 10진 블록, 분수, 수직선 등
- 조작물 단위 앱의 최소 UI 분석에 적합

### Toy Theater Math Manipulatives
- 저학년 친화성
- 시각적 affordance가 강함
- 기능은 단순하지만 '설명 없이도 쓰게 만드는 UI' 비교에 가치

## 우선순위 B

### Mathigon Courses
- Polypad가 학습 콘텐츠 안에 어떻게 embed되는지
- 단계형 설명과 자유 조작을 연결하는 방법
- 콘텐츠 파일과 인터랙티브 컴포넌트의 결합 구조

### Amplify Classroom
- 옛 Desmos Classroom의 후속 플랫폼
- 수업 화면, 교사 대시보드, 학생 응답, Discussion Moment 분석
- 단순 계산기와 수업 플랫폼의 경계 비교

### Wolfram Demonstrations / Wolfram Alpha
- 계산 엔진이 시각화로 이어지는 방식
- 초등보다는 중고등/대학 비교군으로 적합

### CODAP
- 데이터·통계 탐구
- 데이터 테이블, 그래프, 선택 연동
- 객체 간 brushing/linking 구조 분석 가치

## 우선순위 C

### NCTM / Illuminations 계열
- 활동 중심 웹 수학 도구의 역사적 비교
- 최신 기술 구조보다 교수설계 비교용

### NRICH
- 도구 자체보다 문제 설계와 탐구 흐름 분석
- '인터랙션이 적어도 좋은 수학 경험이 가능한가' 비교

### Khan Academy interactive math
- 연습·힌트·마스터리 중심
- open-ended tool과 정반대의 평가 시스템 비교
